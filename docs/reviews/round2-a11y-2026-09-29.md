  labelledby `titleHeading`), help (`:170`, labelledby), intro (`:242`,
  aria-label), final (`:249`, aria-label), credits (`:257`, labelledby),
  end (`:275`, labelledby). Canvas is `tabindex="-1"` with aria-label (`:17`);

- Focus moves into every dialog on open: `helpCloseButton` (`game.js:5115`),
  `skipIntroButton` (`:5154`), `skipFinalButton` (`:5279`),
  `creditsContinueButton` (`:5296`), `againButton` (`:2645`), `startButton` on
  return-to-select (`:2677`); help close returns to `helpButton` or canvas
  (`:5120-5121`). `aria-pressed` synced on world/difficulty/character
  (`:2770-2780`). `button:focus-visible` 3px `#9ee7ff` + glow (`style.css:618-622`).
- Gaps: (a) no focus trap — Tab can leave the modal into the background;
  (b) no `inert`/`aria-hidden` on background content while a modal is open;

## 4. Zoom / selection — PARTIAL (browser zoom ok, gesture zoom blocked)

- Viewports allow scaling: game `maximum-scale=5.0` (`index.html:5`); guide has
  no maximum (`guide.html:5`); root redirect page has no maximum (`index.html:5`).
  Overlays scroll (`overflow:auto`, `style.css:160,338`), so 200% browser zoom reflows.
- Blockers on the game page: `html,body { touch-action:none; user-select:none;
  overflow:hidden }` (`style.css:12-21`), `canvas { touch-action:none }` (`:67`),
  stick/buttons `touch-action:none` (`:834-841`), plus `preventDefault` on
  `pointerdown` for canvas/stick/all four action buttons
  (`game.js:4975,5017,5043-5057`). This disables pinch-zoom and double-tap zoom
  gestures over the whole game surface. Recommend scoping `touch-action:none` to
  canvas + stick only, and `touch-action:manipulation` elsewhere.
- Selection: only `#helpScreen`/`#creditsScreen` text is selectable
  (`style.css:38-45`); title/world/character/end text is not. `guide.html` (separate
  document) is fully selectable. Reading surfaces pass; game surfaces intentionally locked.

## 5. HUD portrait — DEGRADED but usable

- Desktop HUD: 6-column grid (`style.css:76`); ≤820px: 3 columns with meter
  full-width (`:998-1013`); `orientation:portrait` override collapses to
  `1fr auto` (`:1081`) so 6 chips wrap to ~3 rows over the letterboxed canvas
  (`canvas{object-fit:contain}`, `:1076-1078`). Short-landscape query compacts to
  5 columns, hides `#levelName`, drops to 10px (`:1195-1228`).
- HUD is `pointer-events:none` with text-shadow + blur chips (`:70-91`), safe-area
  insets throughout — no touch occlusion by HUD itself. Mobile controls sit at
  bottom safe-area with 0.82/0.72 opacity (`:994`,`:1243`).
- Portrait works (HUD wraps, controls reachable) but the playfield is small and the
  HUD stack covers the top band; manifest + guide both steer to landscape (see §6).
  Recommend a portrait-compact HUD row (smaller chips, single scroll row) if portrait
  must be first-class; otherwise keep landscape-preferred labeling.

## 6. PWA manifest — NEEDS FIX (orientation lock + icon gaps)

Inspected `game/manifest.webmanifest` (21 lines): `name`, `short_name`,
`start_url ./index.html`, `display:fullscreen`, `orientation:landscape`,
`background/theme #101927`, icons 512-png + svg-any. Linked `?v=118`
(`index.html:12`) with `theme-color`, `apple-touch-icon`, `apple-mobile-web-app-capable` (`:6-11`).
- `orientation:"landscape"` locks the installed app to landscape — fails WCAG 1.3.4
  orientation for portrait/bed-mounted users. Recommend `"orientation":"any"`.
- `display:"fullscreen"` hides all browser chrome including zoom/a11y controls;
  prefer `"standalone"`.
- Icons: no 192x192 PNG, no `purpose:"maskable"` (or `"any maskable"`); Android
  installability/masking relies on the single 512 + SVG. Add 192 + maskable purpose.
- Missing optional fields: `id`, `scope`, `description`, `categories`, screenshots.
- Root `index.html` uses a 0s meta-refresh + JS `replace` redirect (`:6`,`:41`) but
  provides a fallback link (`:34`) — acceptable, no timed-redirect a11y failure.

## 7. Dimmed-text contrast — PASS except locked labels

- Base cream `#fff9dc/#fff8d3` on `#101927` ≈ 14–15:1. `.title-credits` 0.74-alpha
  (`:199`) ≈ 9:1 at 12–15px — pass. Help paragraphs 0.88-alpha (`:371`,`:404`) —
  pass. `#f6dc75` rules/load-status, `#bdefff` progress, `#9ee7ff` control terms —
  pass. Action glyphs are dark-on-solid (`#f6dc75/#9ee7ff/#fff4a8/#fff8d3`) —
  pass despite 0.72–0.82 parent opacity. Focus ring `#9ee7ff` 3px — pass 3:1.
- FAIL (informative state): `.locked`/`:disabled` chips use `opacity:0.38` +
  grayscale + dim background (`style.css:759-770`), dragging the cream text to
  ≈ 2–2.5:1; the `LOCKED / BLOQUEADO` suffixes are 9–10px at 0.78-alpha inside
  the 0.38 parent (`:772-786`) — tiny and faint. Disabled controls are formally
  exempt from 1.4.3, but the *locked state itself* is information. Recommend
  raising locked opacity to ≥0.60 and the suffix to ≥11px bold without changing hue.
- Note: HUD/status text drops to 10–11px on mobile (`:1023-1030`,`:1215-1228`).
  Contrast passes (cream on dark chip) but size is below readability guidance;
  acceptable for mirrored HUD values, not for primary reading.

## Fixes (priority order)

1. Manifest: `orientation:any`, `display:standalone`, add 192px + maskable icons.
2. Dialogs: focus trap + `inert` background + Escape on all six dialogs; add
   video caption tracks / transcript for intro speech lines.
3. Touch: scope `touch-action:none` to canvas + stick; `manipulation` elsewhere
   so pinch-zoom works; stack `.title-actions` below ~560px.
4. Locked labels: opacity ≥0.60, suffix ≥11px bold.
